# Film!

![Film!](<img width="230" height="88" alt="image" src="https://github.com/user-attachments/assets/2af1ccb1-0be0-4da6-b109-734c41f59db1" />)

Современный веб-сервис для онлайн-бронирования билетов в кинотеатр. Платформа позволяет пользователям просматривать актуальную афишу, изучать расписание сеансов и безопасно бронировать места в зале. 

Проект демонстрирует профессиональный подход к эволюции архитектуры: бэкенд был успешно мигрирован с документоориентированной MongoDB на реляционную СУБД PostgreSQL с использованием TypeORM. Благодаря применению паттерна «Репозиторий» и строгой типизации DTO, замена слоя данных произошла без изменения логики контроллеров и сервисов, сохранив полную совместимость с React-фронтендом.

**Демо:** http://159.194.245.53/

## Технологический стек

### Frontend
* **Ядро:** React 18, TypeScript
* **Сборка и стили:** Vite, Sass (SCSS Modules)
* **Утилиты:** `clsx` (гибкое управление CSS-классами), `dayjs` (форматирование дат и времени сеансов)
* **Документирование UI:** Storybook (с набором аддонов для тестирования и отображения компонентов)
* **Инструменты качества:** ESLint, Prettier, TypeScript ESLint
* **Пакетный менеджер:** pnpm

### Backend
* **Ядро:** NestJS 10, TypeScript
* **База данных:** TypeORM, `pg` (PostgreSQL) — *основная и актуальная СУБД проекта*
* **Инфраструктура NestJS:** `@nestjs/config` (переменные окружения), `@nestjs/serve-static` (раздача статических файлов афиш)
* **Утилиты:** `uuid` (генерация уникальных идентификаторов), `debug`
* **Тестирование:** Jest, Supertest (модульное и E2E тестирование контроллеров и сервисов)
* **Инструменты качества:** ESLint, Prettier, TypeScript ESLint

### Инфраструктура и инструменты
* Docker, Docker Compose (контейнеризация приложения и базы данных)
* Postman (коллекции для тестирования API)
* Git, GitHub
